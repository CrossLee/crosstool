# Crosio Windows 11 预览版

现在提供普通用户可直接双击的 **Windows 11 中文图形安装程序**，自动选择 x64 或 ARM64，不需要使用 PowerShell、输入命令或另外安装运行库。

下载下面的 `Crosio-Windows-…-Setup.exe`，双击 → 确认 Windows 管理员授权 → 点击“安装” → “完成”。之后从开始菜单打开 Crosio，也可以在完成页勾选立即打开。卸载入口在 Windows“设置 → 应用 → 已安装的应用 → Crosio”。

安装包内已包含完整应用，安装无需联网；翻译模型首次下载另需联网。发布页的 `SHA256SUMS.txt` 是安装程序的校验值，普通用户无需下载它才能安装。

本版仍是**未签名预览版**，Windows 可能显示未知发布者或安全提示；安装器不会导入信任证书、关闭安全功能或永久修改脚本执行策略。它不是正式受信任的生产发行版，也不代表所有功能已经与 macOS 完成一致性验收。如果设备策略禁止未签名程序，请联系管理员，不要关闭安全设置。

当前测试版需使用本人具有管理员权限的 Windows 账户安装；如果授权时换用了另一管理员账户，安装器会停止并提示，避免安装到错误账户。

## 本轮自动验收证据

- x64：289 项自动测试、应用启动探测以及原生“复制路径”命令的系统剪贴板 smoke 验收通过；原生验收覆盖 Unicode 文件、文件夹和多选，并确认没有启动 Crosio 主程序。
- ARM64：只有在本次工作流的 Windows 11 ARM64 托管环境实际点击安装向导、确认安装成功并验证应用启动后，本预览发布任务才会运行。这证明图形安装与启动链路通过，不等同于其他功能交互验收或实体设备测试。
- 发布资产直接取自上述同一次工作流，不从开发电脑重新上传；发布前会核对版本、精确文件清单和 SHA-256，并在云端下载复验后才公开预览版。

## 仍需人工验收

以下项目不能由当前自动化结果替代，仍需在实际 Windows 11 设备上检查：

- 区域截图、截图编辑、贴图及快捷键交互；
- 屏幕、窗口和区域录屏，包括系统声音与生成的 MP4；
- 中文、英文图片的本地 OCR 结果；
- 安装后的资源管理器右键菜单是否显示、位置是否合理以及实际交互；
- 多显示器、不同缩放比例和跨屏场景。

发现问题时，请附上 Windows 版本、x64/ARM64 架构、显示器缩放比例、操作步骤和错误信息；不要上传含私人内容的原图、识别文本或局域网共享令牌。
