# Crosio Windows 11 预览版

这是供测试使用的**未签名 Windows 11 预览版**，包含可自动选择 x64 或 ARM64 架构的通用 MSIXBundle。它不是正式受信任的生产发行版，也不代表 Windows 版已经与 macOS 版完成全部功能一致性验收。

下载 `Crosio-Windows-…-unsigned-preview.zip` 后请完整解压。发布页的 `SHA256SUMS.txt` 用于核验 ZIP；ZIP 内的同名校验文件用于核验安装包、安装脚本和随附文档。具体安装方式及未签名测试包说明请阅读 ZIP 内的 `TESTING.md`。

## 本轮自动验收证据

- x64：289 项自动测试、应用启动探测以及原生“复制路径”命令的系统剪贴板 smoke 验收通过；原生验收覆盖 Unicode 文件、文件夹和多选，并确认没有启动 Crosio 主程序。
- ARM64：只有在本次工作流的 Windows 11 ARM64 托管 runner 环境完成组合包安装和应用启动后，本预览发布任务才会运行。这证明安装与启动链路通过，不等同于 ARM64 功能交互验收，也不是用户实体设备验收。
- 发布资产直接取自上述同一次工作流，不从开发电脑重新上传；发布前会核对版本、精确文件清单和 SHA-256，并在云端下载复验后才公开预览版。

## 仍需人工验收

以下项目不能由当前自动化结果替代，仍需在实际 Windows 11 设备上检查：

- 区域截图、截图编辑、贴图及快捷键交互；
- 屏幕、窗口和区域录屏，包括系统声音与生成的 MP4；
- 中文、英文图片的本地 OCR 结果；
- 安装后的资源管理器右键菜单是否显示、位置是否合理以及实际交互；
- 多显示器、不同缩放比例和跨屏场景。

发现问题时，请附上 Windows 版本、x64/ARM64 架构、显示器缩放比例、操作步骤和错误信息；不要上传含私人内容的原图、识别文本或局域网共享令牌。
