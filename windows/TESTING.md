# Crosio Windows 测试版使用说明

这是 Windows 11 测试版，不是已经完成真机验收的正式版。自动测试、编译成功和生成安装包，不能代替下面的桌面交互验收。x64 与 ARM64 需要分别测试。

## 安装与启动

1. 下载并完整解压同一个版本的测试包；保留 `Install-Crosio.ps1` 与 `.msixbundle` 在同一目录。
2. 可先用 `Get-FileHash -Algorithm SHA256 <安装包路径>` 对照 `SHA256SUMS.txt` 核验下载文件。
3. 对于文件名含 `unsigned-test` 的包，在该目录打开**管理员 PowerShell**，运行：

   ```powershell
   powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\Install-Crosio.ps1
   ```

   这只对本次安装脚本设置执行策略，不永久修改系统策略。脚本使用 Windows 11 的 unsigned package 测试安装机制，不导入证书，也不会跳过无效签名。
4. 从开始菜单打开 Crosio。关闭主窗口后，程序留在通知区域；退出请使用托盘菜单中的“退出”。

组合包会选择匹配的 x64 或 ARM64 架构。测试包没有正式代码签名，不能把它当成正式受信任的发行包；不要用于无人值守批量部署。

## 建议先验收这几个操作

- 区域截图：按 `Ctrl+Shift+1`，选一个小区域，立刻到其他程序粘贴，确认已有图片。关闭截图编辑器只需一次 `Esc`，主界面不应被重新打开。
- 截图贴图：截图编辑器按 `S`，确认只有所选小图置顶；滚轮缩放，`Esc` 关闭。
- 右键复制路径：分别测试中文文件名、文件夹、多选文件；路径应正确，主界面不应弹出。此项必须安装 MSIX，直接运行解压目录不会注册资源管理器菜单。
- 图片打开方式：选择“打开方式 → Crosio”，应自动压缩并在资源管理器定位结果；原文件不能被覆盖，输出后缀和真实编码要保持一致。
- 自动 OCR：截取含中文和英文的区域，检查识别文本。此功能在本机运行，不上传截图。
- 文本翻译：先在设置中设置翻译快捷键，并在翻译页安装中英双向模型。选中中文或英文后按快捷键，应自动填入并翻译为另一种语言。首次下载模型需要联网；模型安装后的推理不联网。
- 录屏：分别录制屏幕、区域、窗口，停止后播放 MP4，检查画面、系统声音和鼠标。Windows N/KN 需先启用系统的 Media Feature Pack。
- 长截图：测试浏览器长页面的上下衔接、固定页头和到达底部；不要只检查是否生成了图片文件。
- 共享：在同一局域网的另一台设备打开共享链接，测试文件下载、文件上传和文字发送；按“停止共享”后旧链接必须失效。
- 开机启动：在 Crosio 设置启用后注销并重新登录；应只驻留通知区域，不弹主窗口。关闭该设置后再次登录确认不会启动。

## 遇到问题

请记录 Windows 版本、处理器架构、测试包版本、具体操作和报错；截图或录屏问题还需要注明显示器缩放比例、是否多屏。不要发送包含私人内容的原图、文本或共享令牌。

卸载可从 Windows“设置 → 应用 → 已安装的应用 → Crosio”进行。未完成验收前请保留原来的 macOS 版本，本测试包不会修改 Mac 上的应用。
