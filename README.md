# 一爪 · Windows 开发分支

一爪是本地优先的桌面工具箱，提供截图、OCR、图片压缩、录屏、取色、翻译和局域网分享。

这是原生 Windows 版本的开发分支。产品介绍、界面预览和当前公开下载入口，请前往 **[项目首页](https://github.com/CrossLee/onepaw#readme)**。

- [Windows 安装、功能与构建说明](windows/README.md)
- [Windows 测试与预览版限制](windows/TESTING.md)
- [已公开版本](https://github.com/CrossLee/onepaw/releases)
- [问题反馈](https://github.com/CrossLee/onepaw/issues)

当前品牌更名候选为 `0.1.21.0`。新界面与安装包显示“一爪”，但应用内部安装身份与数据路径保持兼容。当前预览版仍未取得 Windows 可信签名；代码提交、Actions 构建和公开 Release 是不同阶段，以实际发布记录为准。
