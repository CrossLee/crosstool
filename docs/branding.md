# 一爪品牌与升级兼容

产品显示名统一为 **一爪**，英文品牌为 **OnePaw**。口号为“电脑小事，一爪搞定”。

## 新版本的对外名称

- macOS 0.6.6 起：应用实体 `一爪.app`；窗口、菜单栏、权限说明、登录项说明、Finder 关联与共享网页均使用一爪。
- Windows 0.1.21.0 起：窗口、托盘、开始菜单、图片打开方式、右键菜单、安装器和卸载显示名均使用一爪。
- 新生成的安装包使用“一爪”前缀。压缩结果使用 `原文件名-一爪.原后缀`；重名依次追加编号，不覆盖原文件。
- 旧名称和新名称版本的签名状态分开核验：macOS 的 Developer ID 不等于 Windows 可信签名；Windows 当前仍是未签名预览。

## 不跟随品牌更改的标识

这些不是面向用户的旧品牌展示，而是防止升级失效、历史数据丢失或既有集成失效所需的兼容标识：

| 范围 | 保留内容 |
| --- | --- |
| macOS | Bundle ID `com.cross.crosstool`、PKG receipt `com.cross.crosstool.pkg`、`CrossToolApp` 可执行文件与 Swift 模块 |
| Mac 数据 | `~/Library/Application Support/crosstool` 与现有偏好设置键 |
| Windows | Package Name/Publisher/PFN/AUMID、协议/COM GUID、内部程序集与可执行文件、既有存储路径 |
| 局域网协议 | 已发布的鉴权请求头和 API 字段，不因显示名修改破坏客户端兼容 |

旧发布资产、历史哈希、旧应用路径与测试夹具名称按真实记录保留；不会把旧安装包改一个文件名后冒充新版本。

## Mac 旧名称升级

从旧名称安装升级，优先使用 **PKG**，不要先删除旧应用或用户数据。

安装器会校验同名应用的准确 Bundle ID、有效签名和签名团队，拒绝未知身份、符号链接、运行中应用及冲突。校验通过后先保存独立备份；只有新应用验签通过，才归档已确认的旧名称实体。

恢复用备份位于系统级 `/Library/Application Support/crosstool/UpgradeBackups.noindex`，不会写入或清空用户的兼容数据目录。备份被排除在常规索引之外，避免作为重复应用出现在搜索列表中。

DMG/ZIP 适合新安装，不自动执行旧名称迁移。直接拖入新名称应用不会自动替换旧名称目录。
